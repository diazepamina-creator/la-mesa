# La mesa · ruta de estudio

App personal (PWA) para seguir una ruta de estudio sin ir picando de libro en libro.

- Abre `https://diazepamina-creator.github.io/la-mesa/` en Chrome (Android) y elige **Añadir a pantalla de inicio**.
- Los datos (sesiones, progreso, notas) se guardan solo en el navegador del móvil; haz copias desde Ajustes.
- `ruta.json` es la ruta actual y sirve de plantilla para subir otras desde Ajustes.
